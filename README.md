# make-and-take
NJAAPT make-and-take ancillary files

## slow accelerator

Shared at Montclair HS on October 17, 2026.


Runs on base python3. Tested on 3.13.1
Requires a directory called `svg` in the same directory as the script.
The defaults are set to make a $98\ \text{mm}$ disc that fits a $1/2\text{"}$ ($12.7\,\text{mm}$) diameter wood axel.
The resulting disc has been tested when cut on a glowforge plus with medium thickness (1/8\", $3.2\,\text{mm}$) acrylic.
